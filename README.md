# plp-da-a4-student-eda-and-board-report
# Assignment 4: Student Performance EDA and Duka Board Visual Report

## Overview
This repository contains two professional analytics engagements completed as part of the Data Analytics program:
1. **County Education Office Engagement (`student_eda.ipynb`)**: An exploratory data analysis (EDA) of 1,200 student records to identify learners most at risk and evaluate key performance drivers.
2. **Duka Electronics Board Engagement (`board_report.ipynb`)**: A strategic H1 2026 sales analysis, single-page executive visual report, and live Looker Studio dashboard designed for non-technical executives.
